Quem somos

A Rotha IA cria sistemas de gestão sob medida para empresas de diferentes setores.

Atividades

  • Desenvolver e manter aplicações web com React e TypeScript.
  • Implementar regras de negócio, funções e serviços no Supabase (PostgreSQL e Edge Functions).
  • Criar e consumir APIs REST e integrar os sistemas com serviços externos, como nota fiscal, WhatsApp, pagamentos e automações.
  • Modelar tabelas, escrever consultas e cuidar da integridade dos dados.
  • Corrigir bugs reportados pelos clientes, investigando a causa do problema da tela até o banco de dados.
  • Realizar testes e validações das funcionalidades antes de cada entrega.
  • Publicar novas versões e aplicar mudanças de banco em produção, seguindo o checklist da empresa.
  • Propor opções de tela seguindo o design system de cada sistema.
  • Participar de revisão de código e programar em dupla com o fundador.
  • Apoiar a análise de requisitos e a estimativa de tarefas.
  • Documentar funcionalidades e escrever manuais para as equipes dos clientes.
  • Usar Git para controle de versão e o nosso sistema interno de tarefas.

Requisitos

  • Ensino superior completo ou em andamento em Ciência da Computação, Sistemas de Informação, Engenharia de Software, Análise e Desenvolvimento de Sistemas ou área relacionada.
  • Experiência de pelo menos 1 ano com React e TypeScript, em emprego, freela ou projetos próprios publicados.
  • Conhecimento em banco de dados relacional e SQL (PostgreSQL ou Supabase).
  • Experiência com integração de APIs REST.
  • Git no dia a dia.
  • Autonomia e IA: saber gerenciar o estado da aplicação, fazer requisições HTTP e implementar autenticação, e usar ferramentas de IA (Claude Code, Cursor ou similar) para ganhar produtividade sem ficar dependente delas, sabendo explicar o código que entregou.
  • Capacidade de investigar um problema de ponta a ponta e explicar com clareza o que encontrou.
